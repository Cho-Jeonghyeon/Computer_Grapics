main.cpp 기반 · 실선은 의도된 동작, 붉은 선은 현재 실제 경로현재 즉시 종료 버그 있음

무엇을 만드는 코드인가

  • 화면을 4개 영역으로 나눠 각각 무작위 배경색을 칠합니다.
  • 숫자 1~4로 해당 영역 중앙에 무작위 크기·색상의 사각형을 만듭니다.
  • 각 영역은 사각형을 최대 5개까지 보관합니다.

조작법

  • 클릭: 위에 그려진 사각형부터 역순으로 찾아 선택
  • +/−: 선택 크기 변경 · C: 색 변경
  • R: 전체 초기화 · Q: 종료

현재 실제 동작

  • 37행의 if (!glfwInit())가 주석 안으로 들어가 있습니다.
  • 뒤의 중괄호 블록이 조건 없이 실행되어 오류를 출력하고 즉시 종료합니다.
  • 61행의 glewExperimental = GL_TRUE;도 같은 방식으로 주석 처리돼 있습니다.
