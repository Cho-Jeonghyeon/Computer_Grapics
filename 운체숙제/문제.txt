procs — 프로세스 상태
항목	영어 원뜻	한글 의미
r	Runnable	실행 중이거나 CPU 실행을 기다리는 프로세스 수
b	Blocked	입출력 완료 등을 기다리며 막혀 있는 프로세스 수

memory — 메모리 사용 상태
항목	영어 원뜻	한글 의미
swpd	Swap used	현재 사용 중인 스왑 공간
free	Free memory	현재 사용되지 않는 물리 메모리
buff	Buffers	버퍼로 사용 중인 메모리
cache	Cache	파일 등의 데이터를 캐시하는 데 사용 중인 메모리

swap — 스왑 입출력
항목	영어 원뜻	한글 의미
si	Swap In	디스크의 스왑 공간에서 메모리로 가져온 양/초
so	Swap Out	메모리에서 디스크의 스왑 공간으로 내보낸 양/초

io — 입출력
항목	영어 원뜻	한글 의미
bi	Blocks In	블록 장치에서 읽어 온 데이터량/초
bo	Blocks Out	블록 장치로 기록한 데이터량/초

system — 시스템 활동
항목	영어 원뜻	한글 의미
in	Interrupts	초당 발생한 인터럽트 수
cs	Context Switches	초당 발생한 문맥 교환 수

cpu — CPU 시간 비율
항목	영어 원뜻	한글 의미
us	User	사용자 모드에서 실행한 시간 비율
sy	System	커널 모드에서 실행한 시간 비율
id	Idle	CPU가 유휴 상태였던 시간 비율
wa	I/O Wait	입출력 대기와 관련된 CPU 시간 비율
st	Steal	가상 머신에서 다른 작업에 빼앗긴 CPU 시간 비율
