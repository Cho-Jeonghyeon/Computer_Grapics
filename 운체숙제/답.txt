1. 운영체제가 제공하는 메모리 가상화란?
각 프로세스에 독립적인 가상주소공간을 제공하여, 마치 자신만의 메모리를 사용하는 것처럼 보이게하는 기술이다.
(프로세스가 사용하는 가상 주소는 mmu와 페이지 테이블 등의 주소변환 메커니즘을 통해 실제 물리 주소로 변환된다.)

3. COW(Copy-On-Write)란? 예시를 서술하시오
COW는 프로세스를 복제할 때 메모리 내용을 즉시 복사하지 않고, 부모와 자식이 동일한 물리 페이지를 공유하다가 어느 한쪽이 쓰기를 시도할 때 해당 페이지를 복사하는 기술이다.

4. 5. int *p = NULL; *p = 10; 실행 시 오류가 발생하는 이유
NULL 포인터는 유효한 메모리를 가리키지 않으므로 *p = 10은 잘못된 메모리 접근이다. 일반적인 리눅스 환경에서는 MMU가 접근 위반을 감지하여 페이지 폴트 예외를 발생시키고, 운영체제가 SIGSEGV 신호를 보내 프로세스를 종료시킨다.

5.왜 Min-heap 대신 Red-Black Tree인가?
CFS는 각 프로세스의 vruntime을 기준으로 CPU 사용 시간을 공정하게 배분한다. 이를 위해 vruntime이 가장 작은 프로세스를 선택할 뿐 아니라, I/O 요청과 완료 등에 따라 실행 가능 프로세스를 삽입하고 제거해야 한다. Red-Black Tree는 균형 이진 탐색 트리로서 O(log N)의 삽입과 삭제를 보장하며, vruntime에 따른 정렬 순서를 유지할 수 있다. 반면 Min-heap은 최솟값 선택에는 효율적이지만 정렬된 순서 탐색에는 불리하므로 CFS의 실행 큐 관리에 RB-tree가 적합하다.

6.MLFQ와 CFS의 차이점을 설명하시오.
MLFQ는 프로세스의 CPU 사용 행동에 따라 우선순위를 변경하고, 대화형 작업의 응답성을 개선하는 데 초점을 둔다. CFS는 가중치가 반영된 vruntime을 이용해 프로세스마다 공정한 CPU 실행 기회를 제공하는 데 초점을 둔다.

7. 선형 페이지 테이블 크기가 너무 커지는 문제를 해결하는 방법을 서술하시오.
선형 페이지 테이블은 가상 페이지 수에 비례하여 크기가 증가하며, 사용하지 않는 가상 주소 영역에 대해서도 항목을 유지해야 하므로 메모리를 낭비할 수 있다. 이를 해결하기 위해 페이지 크기를 키워 페이지 수를 줄이거나, 세그멘테이션과 페이징을 혼합해 영역별 페이지 테이블을 사용할 수 있다. 또한 멀티레벨 페이지 테이블을 사용하면 사용하지 않는 영역의 하위 페이지 테이블을 생성하지 않아 메모리를 절약할 수 있다. 역 페이지 테이블은 물리 프레임 수를 기준으로 관리하여 테이블 크기를 줄이는 방법이다.






malloc()이 시스템 콜이 아닌 이유를 설명하시오.
malloc()은 사용자 공간의 메모리 할당 라이브러리 함수이다. 이미 확보된 힙 공간에서 메모리를 제공할 수 있으므로 호출할 때마다 커널에 진입할 필요가 없다. 필요한 경우 brk() 또는 mmap() 등의 시스템 콜을 통해 추가 가상 메모리 공간을 확보한다.

Demand Paging(요구 페이징)의 원리와 사용 예를 설명하시오.
요구 페이징은 모든 가상 페이지를 처음부터 물리 메모리에 적재하지 않고, 실제 접근이 필요할 때 적재하는 기법이다. 필요한 페이지가 물리 메모리에 없으면 페이지 폴트가 발생하고, 운영체제가 해당 페이지를 디스크에서 가져오거나 새 페이지를 준비하여 매핑을 갱신한다. 예를 들어 큰 프로그램을 실행할 때 실제 실행되는 코드나 접근하는 데이터 페이지만 물리 메모리에 적재하여 메모리를 효율적으로 사용할 수 있다.


TLB가 필요한 이유를 설명하시오.
페이징에서는 가상 주소를 물리 주소로 변환하기 위해 페이지 테이블을 조회해야 한다. 페이지 테이블이 메모리에 저장되어 있다면 주소 변환 과정에서 추가적인 메모리 접근 비용이 발생한다. TLB는 최근 사용한 VPN과 PFN의 대응 정보를 캐싱하여 이러한 주소 변환 비용을 줄이기 위한 하드웨어이다.


멀티레벨 페이지 테이블의 동작 원리를 설명하시오.
멀티레벨 페이지 테이블은 가상 페이지 번호를 여러 부분으로 나누어 단계적으로 주소를 변환하는 방식이다. 상위 비트를 이용해 페이지 디렉터리를 조회하여 하위 페이지 테이블의 위치를 찾고, 다음 비트로 하위 테이블의 PTE를 조회해 PFN을 얻는다. 사용하지 않는 영역의 하위 페이지 테이블을 생성하지 않아 메모리를 절약할 수 있지만, TLB 미스 시 여러 단계의 메모리 접근이 필요할 수 있다.


예상: 역 페이지 테이블의 장점과 단점을 설명하시오.
역 페이지 테이블은 가상 페이지가 아니라 물리 프레임을 기준으로 항목을 관리하므로 큰 가상 주소 공간에서도 페이지 테이블의 크기를 줄일 수 있다. 하지만 특정 가상 페이지가 어느 물리 프레임에 매핑되어 있는지 직접 찾기 어렵기 때문에 해싱 등의 추가적인 조회 기법이 필요할 수 있다.


TLB 미스와 페이지 폴트의 차이를 설명하시오.
TLB 미스는 TLB에 해당 VPN의 주소 변환 정보가 없는 상황이며, 페이지가 이미 물리 메모리에 존재할 수도 있다. 반면 요구 페이징에서의 페이지 폴트는 접근한 페이지가 물리 메모리에 없어 운영체제의 처리가 필요한 상황이다. 따라서 TLB 미스가 발생했다고 반드시 페이지 폴트가 발생하는 것은 아니다.
